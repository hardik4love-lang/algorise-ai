# Algorise AI Solutions ("Rise Above with AI.")

Welcome to the brand and web asset repository for **Algorise AI Solutions** (`algorise.ai`).

---

## What's Included

* **`index.html`**: Complete, responsive, high-converting landing page.
  * Dark mode enterprise aesthetics (Tailwind CSS, Plus Jakarta Sans, JetBrains Mono)
  * Live interactive **AI Pipeline Simulator** with real-time stage tracking
  * Interactive **Project Scope & Timeline Estimator**
  * Core capabilities showcase (Multi-Agent Swarms, Computer Science Architecture, Vector RAG)
  * Priority consultation intake modal form
  * Embedded branding and vector iconography (Lucide Icons)
* **`assets/logo.jpg`**: High-resolution generated logo concept combining an architectural letter "A" with ascending neural graph nodes.
* **`CLIENT_PROPOSAL_TEMPLATE.md`**: Ready-to-use technical proposal template for pitching prospective B2B clients and enterprise partners.

## How to Preview the Landing Page

### Option 1: Direct in Browser
Double-click `index.html` in your file explorer, or run the following command in PowerShell:
```powershell
Start-Process "C:\Users\om\.gemini\antigravity\scratch\algorise-ai\index.html"
```

### Option 2: Local HTTP Server (Python)
```powershell
cd C:\Users\om\.gemini\antigravity\scratch\algorise-ai
python -m http.server 3000
```
Then visit `http://localhost:3000` in your web browser.
